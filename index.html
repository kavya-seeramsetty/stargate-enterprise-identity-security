02 / Security controls

The project focuses on controls that can be demonstrated, tested, and investigated instead of simply configured.

GPO

60-second screen lock

Screen saver and password protection were configured. Troubleshooting revealed that forcing a specific screen saver was required for the intended behavior to apply successfully.

AUTHENTICATION

Account lockout

Five failed attempts were used to trigger lockout, followed by controlled investigation and unlock validation.

AUDITING

Security events

Authentication, account, group membership, and privileged logon events were investigated using native Windows logs.

Engineering lesson: an “enabled” setting is not the same thing as a working control. StarGate validates behavior on the endpoint.

04 / PowerShell automation

Repeated operational tasks were turned into controlled tools with validation, error handling, reporting, and audit output.

Manage-AccountLockout.ps1

Finds locked accounts, confirms identity, unlocks only after authorization, and records the action.

Disable-Employee.ps1

Offboarding workflow that disables an account, removes department access, moves the user to Disabled-Users, and generates a report.

Get-RecentFailedLogins.ps1

Investigates Event 4625 and extracts useful authentication context for triage.

Audit-PrivilegedGroups.ps1

Compares privileged group memberships against the approved administrative model and reports unexpected members.

New-Employee.ps1

Creates a normal employee account with department placement, group membership, manager validation, and first-login password change.

Get-InactiveUsers.ps1

Included as a future refinement area because inactivity detection needs a stronger operational definition than password age alone.

06 / What this project demonstrates

Think beyond configuration

Controls were tested from the user's and endpoint's perspective.

Troubleshoot methodically

Check → investigate → validate → assess impact → remediate → verify → document.

Automate carefully

Automation includes authorization boundaries, validation, error handling, and useful reporting.
